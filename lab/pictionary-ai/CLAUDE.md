# Pictionary AI
Lightweight web app: Vite vanilla JS client + Express server. Full plan in PLAN.md.
- UI language: English. Code comments in Italian, like lab/glitch-cam. Mobile first (test at 390x844).
- Never expose the API key in client code. The key lives only in .env, read by the server.
- Words only come from server/words.js. No free-text prompts from users.
- Keep dependencies minimal. No frameworks, no database. .env is loaded with Node's --env-file (no dotenv).
- Visual style: flat saturated palette (red, green, blue, light grey), rounded cards,
  serif titles on cards; drawing screens use a single flat background with a
  vertical toolbar on the right (pencil, eraser, undo, timer).
- Hosting: one Render web service (render.yaml at the repo root, steps in DEPLOY.md) serves the
  built game and the API. The portfolio (GitHub Pages) only has the Laboratory card and a waiting
  page in laboratory/pictionary-ai/, generated by build.py (build_lab_wake). Never build the
  game into ../../laboratory/: it needs its server.
- Dev: `npm run dev` starts the API on 127.0.0.1:8787 and Vite on :5174 (Vite proxies /api).
  `npm run dev:lan` also exposes Vite on the local network, to test on a phone.
  The API restarts on changes in server/; restart `npm run dev` after editing .env.
